# TRANZET reference frames

These PNG files are captures of the TRANZET mobile app prototype.

- `canvas-01.png` through `canvas-40.png` are clean canvas captures.
- `frame-01.png` through `frame-40.png` include the prototype viewer context.
- `onboarding-blue.png`, `onboarding-yellow.png`, and `onboarding-purple.png` are cropped onboarding hero artwork used by the native onboarding flow.

The original Figma layers are not available from prototype mode, so these are raster reference assets.
